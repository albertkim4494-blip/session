# Plans Tab — Redesign Brief

This doc is a self-contained snapshot of the **Plans tab** (called `tab === "program"` in code) so a designer / Claude can propose a UI/UX redesign without needing the rest of the repo.

---

## 1. What the Plans tab is

The Plans tab is where users **build and edit the structure of their training**. It is *not* where they log workouts (that's the Train tab). Today it contains four stacked cards:

1. **Exercise Catalog** — single tappable card → opens a modal to browse ~100 catalog exercises.
2. **Splits** — collapsible card listing user-created "splits" (a Split groups workouts that run together, e.g. Push/Pull/Legs or a sport-week routine). Each split shows its members nested inside it. Tapping a split header opens the split editor; tapping a member opens the workout editor.
3. **Programs** — collapsible card listing standalone Workouts (only ones not already part of a Split, unless reorder mode is on). Each workout row expands inline to show its exercises. Per-row icons: share, edit, delete, reorder, add. Bottom: a **Generate Program** button (AI wizard).
4. **Data** — collapsible card with Export JSON / Export CSV / Import / Reset All buttons.

### User goals on this tab
- Set up a multi-week training plan (split + workouts + exercises).
- Quickly find and edit a specific workout or exercise.
- Reorder workouts and exercises.
- Share a workout with a group.
- Generate a full program with AI.
- Export / import / nuke data.

### Known pain points (open for redesign)
- Information density is high — three nested levels (Split → Workout → Exercise) on one scroll.
- Inline expansion of a workout pushes everything below; on long programs this gets disorienting.
- Icon-only action rows (share / edit / delete / reorder / add) are easy to miss and not great on mobile.
- "Splits" vs "Programs" labeling is unclear — users sometimes look for a workout that's been absorbed into a split.
- The "Data" card feels misplaced on a planning tab; competes with the AI Generate button for end-of-page attention.
- AI **Generate Program** is buried at the bottom of the Programs card despite being the highest-leverage entry point for new users.
- The collapsible cards default open and there's no global "what does my week look like" view.

## 2. Tech context (so design proposals stay realistic)

- **React 19 + Vite**, plain JavaScript (no TypeScript).
- **No Tailwind / no CSS files** for app code — all styling is **inline style objects** generated by `getStyles(colors)` in `src/styles/theme.js`. `colors` comes from `getColors(theme)`. Themes: `dark`, `light`, `japandi`, `spring`. (Designs need to work on all four; default is dark.)
- **Mobile-first PWA** — the primary target is phones (Android + iOS, standalone install). Desktop is secondary.
- **Bottom nav** — Plans is one of 4–5 bottom tabs. The tab body scrolls; bottom nav is fixed.
- **Animations** are minimal: `tabFadeIn 0.25s` on tab change, `0.2s` on inline expand. No layout libraries (Framer Motion etc.).
- Cards use 16px radius, 16px padding, 1px hairline border, soft shadow.

### `src/components/SplitsSection.jsx` (essence)

```jsx
export function SplitsSection({ splits, workouts, onCreateSplit, onEditSplit, onEditWorkout, styles, colors }) {
  const workoutById = new Map((workouts || []).map(w => [w.id, w]));
  const hasAny = (splits || []).length > 0;

  return (
    <div className="card-hover" style={styles.card}>
      <div style={{ ...styles.cardHeader, marginBottom: hasAny ? 12 : 0 }}>
        <div style={styles.cardTitle}>Splits</div>
        <button style={{ ...styles.primaryBtn, padding: "6px 10px" }} onClick={onCreateSplit}>
          <PlusIcon/>
        </button>
      </div>

      {!hasAny ? (
        <div style={{ textAlign: "center", padding: "12px 12px 4px", opacity: 0.5, fontSize: 13 }}>
          Group workouts that run together — like a Push/Pull/Legs cycle or a sport-week routine.
        </div>
      ) : (
        <div style={{ display: "flex", flexDirection: "column", gap: 10 }}>
          {splits.map(s => {
            const isContinuous = s.mode === "continuous";
            const memberCount = (s.members || []).length;
            const summary = isContinuous
              ? `Continuous · ${memberCount} in sequence`
              : `Weekly · ${memberCount} ${memberCount === 1 ? "workout" : "workouts"}`;

            return (
              <div key={s.id} style={{ border: `1px solid ${colors.border}`, borderRadius: 12, background: colors.cardAltBg, overflow: "hidden" }}>
                {/* Split header — tap to edit the split */}
                <button onClick={() => onEditSplit(s.id)} style={{ width: "100%", padding: "10px 12px", textAlign: "left" }}>
                  <div style={{ display: "flex", justifyContent: "space-between" }}>
                    <div style={{ fontSize: 14, fontWeight: 700 }}>{s.name}</div>
                    <ChevronRight/>
                  </div>
                  <div style={{ fontSize: 11, opacity: 0.55 }}>{summary}</div>
                </button>

                {/* Members — tap a member to edit the workout */}
                {memberCount > 0 && (
                  <div style={{ borderTop: `1px solid ${colors.border}` }}>
                    {(s.members || []).map((m, i) => {
                      const w = workoutById.get(m.workoutId);
                      const subtitle = isContinuous
                        ? `Day ${i + 1}`
                        : (m.days?.length ? formatDays(m.days) : "Any day");
                      return (
                        <button key={m.workoutId} onClick={() => w && onEditWorkout(w.id)} style={{ display: "flex", justifyContent: "space-between", padding: "10px 12px", borderTop: i === 0 ? "none" : `1px solid ${colors.border}` }}>
                          <div>
                            <div style={{ fontSize: 13, fontWeight: 600 }}>{w?.name || "(deleted workout)"}</div>
                            <div style={{ fontSize: 11, opacity: 0.55 }}>{subtitle}</div>
                          </div>
                        </button>
                      );
                    })}
                  </div>
                )}
              </div>
            );
          })}
        </div>
      )}
    </div>
  );
}
```
